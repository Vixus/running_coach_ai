# Requirements Checklist: Athlete Story / Magazine Spread

_Refreshed 2026-05-07 to match the spec after the 2026-05-06 clarification rounds and the Option-A remediation that removed `block_complete` from v1._

Each item is a binary "is this requirement covered by working, tested code?" Tick when the corresponding tasks have landed AND tests are green.

## Functional Requirements

### Opt-in & onboarding

- [ ] FR-S001 — Story feature is opt-in; `Athlete.story_opt_in` defaults False; no story rows are created when False
- [ ] FR-S027 — Multi-page intro modal renders on first opted-in `/magazine` load; sessions only fire after `story_intro_seen_at` is non-null

### Interview sessions

- [ ] FR-S002 — Athlete answer (option click or free text) populates `StoryQuestion.answer`, `answered_at`, and `is_custom_answer`
- [ ] FR-S003 — At most one active `StoryInterviewSession` per athlete; subsequent triggers are blocked while one is active
- [ ] FR-S028 — Five trigger kinds detected: `pr_set`, `race_upcoming`, `race_complete`, `pace_recalibration`, `difficult_week`; collision priority order enforced
- [ ] FR-S029 — First message of every session is the consent prompt naming the trigger; "Skip" closes the session with `skipped=True`
- [ ] FR-S030 — Adaptive 5–10 question interview generated by Claude per session
- [ ] FR-S031 — Each question persists `options_json` (2–4 strings) at issue time

### Story generation

- [ ] FR-S004 — `race_complete` milestone detected when `CompletedWorkout` matches `Goal.race_date` ±1 day
- [ ] FR-S006 — Editorial generated via Claude on `race_complete` milestone, using profile + Q&A + training stats + HRV
- [ ] FR-S007 — Editorial is 400–600 words, 3–5 paragraphs, in the chosen template's voice (per `template.json:voice_description`)
- [ ] FR-S008 — Unique 12-character URL-safe `share_token` assigned at creation
- [ ] FR-S009 — Bell `Notification` written on generation success (`story_ready`) and failure (`story_failed`)
- [ ] FR-S021 — Regeneration overwrites `editorial_body` in place; preserves `share_token` / `created_at` / `published_at`; 1-hour athlete cooldown; admin bypass

### Templates

- [ ] FR-S032 — Magazine-template registry loads from `web/static/story_templates/<key>/`; ships with 5 v1 templates; new templates added by directory drop only
- [ ] FR-S033 — Auto-selection at generation time combines trigger-affinity prior + Claude vote in the same C-002 call
- [ ] FR-S034 — `POST /api/stories/<id>/template` swaps template; sets `template_locked_by_athlete=True`; no Claude call
- [ ] FR-S035 — When locked, future regenerations inject only the locked voice into the C-002 prompt
- [ ] FR-S036 — Public route falls back to `vogue` if the persisted `template_key` is missing from the registry; logs a warning

### Athlete-facing API

- [ ] FR-S010 — `GET /story/<share_token>` is a public no-auth route
- [ ] FR-S011 — Unpublished stories return 404 except for owner with `?preview=1`; soft-deleted stories return 404 unconditionally and are excluded from athlete-facing lists
- [ ] FR-S012 — "My Story" section in `/magazine` shows cover image, article preview, upload widget, Share button
- [ ] FR-S020 — `GET /api/stories` returns the athlete's non-deleted story list with preview/share URLs
- [ ] FR-S022 — `POST /api/stories/<id>/unpublish` clears `published_at`; share_token preserved
- [ ] FR-S023 — `DELETE /api/stories/<id>` performs soft-delete (`deleted_at = now()`)

### Image upload

- [ ] FR-S013 — Athletes upload up to 5 images per story (JPEG, PNG, WebP; max 10 MB each); stored under `STORY_IMAGE_DIR/<story_id>/`
- [ ] FR-S014 — Caption add/edit per image via PATCH
- [ ] FR-S015 — Image delete before publication
- [ ] FR-S019 — Upload rejected if > 10 MB or MIME not in JPEG/PNG/WebP

### Admin

- [ ] FR-S016 — `POST /api/admin/athletes/<id>/generate-story?milestone=race_complete` triggers generation without a real milestone
- [ ] FR-S017 — Admin generate endpoint returns `{story_id, preview_url}` synchronously after Claude completes (≤30 s target, 60 s timeout returns 504 + `story_failed`)
- [ ] FR-S024 — `DELETE /api/admin/stories/<id>?hard=1` cascade-deletes story + image files + linked sessions
- [ ] FR-S037 — `POST /api/admin/athletes/<id>/start-interview?trigger=<kind>` opens a session bypassing real-trigger detection AND the intro-modal gate
- [ ] FR-S038 — `POST /api/admin/stories/<id>/render?template=<key>` swaps template (admin override; does not set lock flag); 400 on unknown key

### Cross-cutting

- [ ] FR-S018 — Data isolation: all athlete-scoped queries use `scoped_query` per Constitution I; the public route is the one intentional exception (keyed by `share_token`)
- [ ] FR-S025 — Public page renders `<meta name="robots" content="noindex,nofollow">`; `GET /robots.txt` serves `User-agent: *\nDisallow: /story/`
- [ ] FR-S026 — Per-IP sliding-window rate limit (30 req/min) on `/story/<token>`; over-limit returns 429

## Success Criteria (measurable, buildable)

- [ ] SC-S001 — Story generation completes within 30 s of being triggered
- [ ] SC-S002 — Public story page loads in under 1.5 s on local network
- [ ] SC-S003 — Image upload round-trip under 3 s for a 5 MB image
- [ ] SC-S004 — "My Story" section renders within the existing `/api/magazine` hydrate (no additional page-load latency)
- [ ] SC-S005 — Admin generate-story endpoint returns within 30 s sync (per SC-S001); 60 s hard timeout returns 504 + `story_failed`
- [ ] SC-S006 — Trigger detection is idempotent — running activity-poll or morning-check-in twice on the same data produces exactly one `StoryInterviewSession` per qualifying trigger
- [ ] SC-S007 — Athlete template swap completes in under 500 ms
- [ ] SC-S008 — Admin `start-interview` endpoint returns the new `session_id` within 5 s including the first Claude question
- [ ] SC-S009 — Adding a 6th template by dropping a directory under `web/static/story_templates/` and restarting Flask makes it appear in the swap carousel without any database migration
